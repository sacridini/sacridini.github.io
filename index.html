About

I am a Brazilian geographer and data scientist, now a postdoc in Tobias Kuemmerle’s Conservation Biogeography Lab at Humboldt-Universität zu Berlin. My work sits where remote sensing, landscape ecology and optimization meet: mapping how land changes over time, and using those maps to decide where to protect and where to restore.

From 2018 to 2023 I coordinated data science at the International Institute for Sustainability (IIS) in Rio de Janeiro. There I led the team behind PLANGEA, the institute’s spatial planning platform, and worked on the global and national restoration priorities published in Nature and elsewhere, as well as on prioritization projects for governments and companies.

Before that I spent years on monitoring and mapping: dense Landsat and Sentinel time series and change detection during my PhD at UFF, high-resolution mapping for Brazil’s Ministry of the Environment, and large spatial databases at UFRJ. That is where the software habit comes from: I have kept open-source projects on GitHub since 2015, and today I write high-performance tools in Rust, C++ and Python.

Software

Free and open-source tools for remote sensing and spatial ecology. Each reimplements the reference methods of its field, is tested against the original software, and runs from a laptop to a cluster.

Satellite time series

Zeit

Python library with a Rust core

Change detection and time series analysis for Earth observation data cubes, from STAC catalogs to maps of when, where and how much the land changed.

  • CCDC, S-CCD, LandTrendr, BFAST, BEAST, EWMACD, CODED, TWDTW
  • Phenology, unmixing, map validation, deep learning
  • Checked against the original R and author code
import zeit

ndvi = zeit.load_raster("ndvi_stack.tif")
lt   = zeit.landtrendr(ndvi)    # or ccdc, bfast…
loss = zeit.extract_events(lt)  # loss per pixel
zeit.plot(ndvi, fit=lt)
pip install zeit-cdts Documentation
its change detection runs inside

Janus

Desktop app for Windows, macOS and Linux

Explore satellite imagery pixel by pixel, find where and when the land changed, and measure how accurate your maps are. Opens local stacks, cloud-optimized GeoTIFFs and STAC catalogs.

Landscape ecology and conservation planning

landschaft

Python library with a C++/OpenMP core

The methods of landscape ecology in one package: habitat patterns, fragmentation, landscape metrics, connectivity and prioritization, from a single raster to maps larger than memory.

  • Reproduces GuidosToolbox, landscapemetrics, Conefor, Circuitscape, Zonation 5
  • From a few to several hundred times faster
import landschaft as ls

forest = ls.load_raster("forest.tif")
morph  = ls.mspa(forest, edge_width=2)
ls.write_raster(morph, "forest_mspa.tif")
print(ls.mspa_stats(morph))
pip install landschaft Documentation
tested against each other for the same results

Terraflux

Desktop app and command line, written in Rust

Landscape ecology, conservation planning and land change simulation in one visual model builder: more than 340 operators and 45 ready-to-run templates, from a laptop to a Slurm cluster.
